# 팀 업무 대시보드

팀원들과 이번 주 업무 진행 상황과 차주 예정 업무를 함께 확인하는 업무 일정관리 웹 애플리케이션입니다.
백엔드나 로그인 없이 HTML, CSS, JavaScript만으로 동작합니다.

## 주요 기능

- 업무 추가, 수정, 삭제 (업무명, 담당자, 상태, 마감일, 주간 업데이트 메모)
- 이번 주 / 차주 예정 칸마다 "＋ 업무 추가" 버튼: 해당 주의 금요일이 마감일로 미리 채워짐
- 상태 4가지: 예정 / 진행중 / 완료 / 지연 (카드에서 바로 변경 가능)
- 주차 이동(‹ ›)으로 지난 주차 업무 기록 확인, 다른 주차를 볼 때 나타나는 "이번 주로 돌아가기" 버튼으로 복귀
- 이번 주 업무와 차주 예정 업무를 나누어 표시
- 지난 주차에 끝나지 않은 업무는 "지난 주차 미완료 업무"에 따로 표시
- 주간 일정(월~일 7칸): 날짜별 미팅과 업무 마감 건수 표시, 오늘 날짜 강조
- 미팅 등록, 수정, 삭제 (미팅명, 날짜, 시간, 참석자, 장소). 날짜 칸의 ＋로 그 날짜에 바로 추가
- 메모장: 아이디어 / 논의 필요 / 기타로 분류해 빠르게 기록, 완료 체크, 수정·삭제, 분류별 보기 (주차와 무관하게 보관)
- 상단 요약 카드: 진행중 / 완료 / 지연 / 차주 예정 / 이번 주 미팅 개수 (상태 카드를 누르면 해당 상태로 필터링)
- 담당자별, 상태별 필터
- 브라우저 localStorage에 저장되어 새로고침해도 유지
- PC와 모바일 반응형, 다크 모드 지원

## 파일 구성

```
├── index.html   # 화면 구조
├── style.css    # 스타일과 반응형 레이아웃
├── app.js       # 데이터 저장, 주차 계산, 렌더링, 이벤트 처리
└── README.md
```

## 로컬에서 실행

`index.html`을 브라우저로 열면 바로 실행됩니다.

## 배포 (GitHub + Vercel)

1. GitHub에 새 저장소를 만들고 이 폴더의 파일을 올립니다.
   ```bash
   git init
   git add .
   git commit -m "팀 업무 대시보드"
   git branch -M main
   git remote add origin https://github.com/<아이디>/<저장소명>.git
   git push -u origin main
   ```
2. [vercel.com](https://vercel.com)에 GitHub 계정으로 로그인합니다.
3. **Add New → Project**에서 저장소를 선택하고, Framework Preset은 **Other**로 둔 채 **Deploy**를 누릅니다.
4. 발급된 `https://<프로젝트명>.vercel.app` 주소를 공유하면 누구나 접속해 사용할 수 있습니다.

GitHub Pages를 쓰려면 저장소의 **Settings → Pages**에서 `main` 브랜치를 선택하면 됩니다.

## 참고: 데이터 저장 범위

데이터는 **각 사용자의 브라우저에만** 저장됩니다. 같은 URL에 접속해도 사람마다 자신의 업무 목록을 보게 되며, 팀원 간 실시간 공유는 되지 않습니다.
팀 전체가 같은 데이터를 보려면 이후 Supabase, Firebase 같은 데이터베이스를 연결해야 합니다.
처음 접속하면 사용 예시를 보여주기 위해 샘플 업무 7개가 자동으로 추가되며, 자유롭게 삭제할 수 있습니다.
